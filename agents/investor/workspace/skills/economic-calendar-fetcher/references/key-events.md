## 四、事件对A股的影响规律

### 利好信号
- 🟢 CPI 低于预期 → 通胀温和，降息空间大 → 利好股市
- 🟢 PMI > 50 且超预期 → 经济扩张 → 利好周期/制造业
- 🟢 社融超预期 → 货币宽松，信贷扩张 → 利好银行/地产
- 🟢 美联储降息 → 全球流动性宽松 → 利好A股外资流入
- 🟢 GDP超预期 → 经济强劲 → 全面利好

### 利空信号
- 🔴 CPI 超预期上涨 → 通胀压力 → 降息预期降低 → 利空成长股
- 🔴 PMI < 50 → 经济收缩 → 利空周期股
- 🔴 美联储加息/鹰派表态 → 美元走强 → 人民币承压 → 外资流出
- 🔴 非农超强 → 降息预期推迟 → 利空全球股市

### 中性/不确定
- 🟡 数据符合预期 → 市场反应平淡，关注后续政策信号
- 🟡 GDP数据略低于预期 → 可能刺激政策宽松预期 → 反而利好

## 五、季节性规律

| 月份 | 重要节点 | 投资含义 |
|------|----------|----------|
| 1月 | 全年开门红行情 | 春季躁动，布局早周期 |
| 3月 | 两会政策 | 关注政策导向板块 |
| 4月 | 一季报披露 | 业绩分化，警惕雷区 |
| 7-8月 | 半年报季 | 同上 |
| 10月 | 三季报 + 年末布局 | 机构调仓，关注低估值蓝筹 |
| 12月 | 中央经济工作会议 | 来年政策定调，重要布局窗口 |
