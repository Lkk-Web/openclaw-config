# 投资策略方法论

## 核心理念

**先求不亏钱，再求赚钱** —— 任何策略都要先考虑最大风险。

## 五大核心规则

### 1️⃣ 投资目标
- **年化收益目标**：10%+
- **优先原则**：保证不亏钱 > 追求高收益
- **利润保护**：浮盈后制定退出策略（详见 references/profit-protection.md）

### 2️⃣ 投资操作风格
- **交易方向**：偏左侧交易（低吸潜伏，不追高）
- **决策流程**：每次交易必须有完整决策链（见下方）
- **题材埋伏**：关注政策方向、业绩拐点、周期反转等机会
- **管不住手解决方案**：用部分资金配置历史低位且基本面无变化的银行、保险、证券等蓝筹ETF

**决策流程清单**：
```
1. 为什么要买？（逻辑）
2. 买多少？（仓位）
3. 什么时候买？（时机）
4. 什么时候卖？（止盈/止损）
5. 如果买错了怎么办？（应急预案）
```

### 3️⃣ 仓位管理规则
| 规则 | 比例 | 说明 |
|------|------|------|
| 单票上限 | <50% | 除非个人信仰 |
| 现金储备 | ≥20% | 只做冰点加仓 |
| 工资分配 | 1:2 | 1份现金，2份加仓 |

**每周操作限制**：
- 买单：≤1笔/周
- 卖单：≤2笔/周

### 4️⃣ 每日学习
- **时间**：每天 20:00-20:30（半小时）
- **内容**：
  -看书学习（投资经典著作）
  -看新闻联播（政策方向）

### 5️⃣ 专业投资思路
- **ETF配置**：宽基ETF+行业ETF组合，降低个股黑天鹅风险
- **定投纪律**：每月固定日期买入，坚持长期主义
- **逆向思维**：人多的地方不去，在恐慌时贪婪
- **远离杠杆**：杠杆会放大人性弱点
