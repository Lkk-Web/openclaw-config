# 题材分析方法论

核心思想：**提前预判+潜伏等待，而非追涨杀跌**

## 什么是题材

题材 = 预期差 = 未来可能发生的利好

## 题材分类

### 政策类
- 国家政策扶持（新能源、半导体、AI）
- 区域政策（自贸区、开发区）
- 产业政策（补贴、税收优惠）

### 业绩类
- 业绩预增、业绩反转
- 行业景气度回升
- 产品涨价

### 事件类
- 并购重组
- 新产品发布
- 重大合同签订
- 重要会议/展会

### 周期类
- 猪周期（养殖）
- 航运周期
- 大宗商品周期

## 题材分析流程

### 第一步：政策解读
- 关注新闻联播、政策文件
- 理解政策力度和持续性
- 区分"一次性利好"和"长期利好"

### 第二步：产业逻辑
- 政策 → 行业 → 公司 传导链
- 行业天花板有多高？
- 公司受益程度有多大？

### 第三步：选股策略
- **龙头优先** - 行业老大弹性最大
- **ETF次之** - 不确定哪个会涨，买行业ETF
- **小市值优先** - 同等逻辑下，小市值弹性更大

### 第四步：时机选择
- **潜伏期**：政策刚出台，市场还没反应
- **发酵期**：板块开始异动，但还没暴涨
- **加速期**：板块已经大涨，不建议追入
- **收尾期**：高潮后分化，远离

## 埋伏策略

### 1. 研报潜伏
- 读券商研报，找预期差
- 机构重仓但股价未涨的标的
- 目标价与现价有较大空间

### 2. 形态潜伏
- 底部横盘缩量
- 均线粘合
- 多次下探不破新低

### 3. 指标潜伏
- 股东人数持续减少
- 融资融券余额增加
- 大宗交易溢价成交

## 题材卖点

- 达到预期收益（15%+）
- 板块整体大涨（高潮）
- 逻辑兑现或证伪
- 发现更好的题材切换

## 注意事项

1. **不追高** - 追题材容易被套
2. **分散潜伏** - 一个题材买1-2个，不要全仓一个
3. **设止损** - 题材逻辑证伪立即走
4. **快进快出** - 题材炒作周期通常1-3个月
5. **只做看的懂的题材** - 不熟悉的领域不碰

## 决策清单

```
题材分析检查：
□ 这个题材的驱动力是什么？
□ 政策力度有多大？
□ 持续性如何？
□ 哪些公司最受益？
□ 当前处于哪个阶段（潜伏/发酵/加速/收尾）？
□ 计划潜伏多久？

买入计划：
□ 买什么？（龙头/ETF/小市值）
□ 买多少？（单票<10%）
□ 怎么买？（分批建仓）
□ 怎么卖？（止盈/止损）
```
