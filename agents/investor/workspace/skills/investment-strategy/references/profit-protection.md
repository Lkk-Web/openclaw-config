# 盈利保护策略

核心思想：**浮盈后如何保护利润，让利润奔跑的同时锁定部分收益**

## 原则

1. **浮盈不算赢，落袋才是赢**
2. **保护本金 > 保护利润 > 追求更多利润**
3. **分批卖出，永不满仓一把梭**

## 具体方法

### 方法一：移动止损法

当浮盈达到 X% 后，将止损线上移至成本价
- 浮盈 5% → 止损上移至成本价（确保不亏钱）
- 浮盈 10% → 止损上移至成本价+5%
- 浮盈 20% → 止损上移至成本价+10%

### 方法二：分批卖出法

当浮盈达到目标后，分批卖出：
```
浮盈 10% → 卖出 1/3
浮盈 20% → 卖出 1/3  
浮盈 30% → 卖出剩余 1/3
```

### 方法三：回撤止盈法

当浮盈从最高点回撤 X% 时卖出：
- 浮盈 20%，回撤 8% 触发止盈
- 浮盈 30%，回撤 10% 触发止盈
- 浮盈 50%，回撤 12% 触发止盈

## 决策流程

```
浮盈后，我应该：
1. 当前浮盈比例是多少？
2. 是否达到预期卖点？
3. 如果卖出，应该卖多少？
4. 剩余仓位如何保护？
5. 如果行情继续上涨，是否会后悔？
```

## 常见错误

1. **卖早了** → 设定合理的止盈目标，不频繁操作
2. **卖晚了** → 设置回撤止盈，锁定部分利润
3. **太贪了** → 永远不要想把所有利润吃完
4. **过早加仓** → 浮盈加仓是大忌，会拉高成本

## 执行纪律

- 达到止盈点必须执行，不要临时修改
- 除非有新的买入逻辑，否则不卖
- 卖出的资金至少 50% 进入现金储备
