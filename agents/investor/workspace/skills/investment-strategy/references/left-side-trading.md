# 左侧交易方法论

核心思想：**在无人问津时买入，在人声鼎沸时卖出**

## 什么是左侧交易

- **左侧交易**：在下跌趋势中买入，越跌越买
- **右侧交易**：在上涨趋势中买入，追涨杀跌

**你的风格**：左侧交易为主

## 左侧交易的优势

1. **成本优势** - 买在低位，成本天然低于市场
2. **安全边际** - 低位意味着更大的上涨空间
3. **逆向思维** - 符合"别人恐惧我贪婪"
4. **不追高** - 避免追高被套的心理压力

## 左侧交易的核心原则

### 1. 选对标的
- 基本面无变化（业绩稳定、行业地位稳固）
- 行业龙头或ETF
- 历史低位或估值底部
- 没有退市风险

### 2. 分批建仓
```
第一次建仓：10%仓位
第二次建仓（-10%）：+10%
第三次建仓（-20%）：+10%
第四次建仓（-30%）：+10%
```
**每下跌 10% 加仓一次，每次加仓不超过 10%**

### 3. 越跌越买
- 下跌是机会，不是风险
- 但要注意：基本面恶化的下跌不能买
- 区分"价值陷阱"和"价值机会"

### 4. 何时卖出
- 达到预期收益（10%+）
- 基本面发生变化
- 发现更好的投资机会
- 需要资金做其他配置

## 左侧交易信号

### 可以开始左侧买入的信号
- 成交量极度萎缩（地量）
- 舆论极度悲观
- 估值处于历史低位
- 政策开始呵护市场
- 出现止跌企稳信号（连续小阳线）

### 需要暂停或止损的信号
- 基本面持续恶化
- 行业逻辑被颠覆
- 出现重大利空
- 跌幅超过承受极限

## 决策检查清单

```
买入前检查：
□ 基本面是否稳定？
□ 行业是否还有前景？
□ 当前估值是否合理？
□ 下跌空间还有多少？
□ 我能承受多大的浮亏？

建仓计划：
□ 计划买多少仓位？
□ 分几批建仓？
□ 每批间隔多大跌幅？
□ 预计多久能涨？
□ 卖点在哪里？
```

## 常见错误

1. **抄底抄在半山腰** → 分散建仓，不要一次性买满
2. **过早重仓** → 留足现金，等待更低价
3. **死扛不止损** → 设定最大亏损线（-20%）
4. **买了基本面恶化的股票** → 远离"价值陷阱"
