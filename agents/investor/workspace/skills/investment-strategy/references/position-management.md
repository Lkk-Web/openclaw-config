# 仓位管理模型

核心思想：**仓位决定心态，心态决定成败**

## 你的仓位规则

| 规则 | 比例 | 说明 |
|------|------|------|
| 单票上限 | <50% | 除非个人信仰 |
| 现金储备 | ≥20% | 只做冰点加仓 |
| 工资分配 | 1:2 | 1份现金，2份加仓 |

## 仓位计算公式

### 基础仓位模型

```
可投资金 = 总资金 × (1 - 现金比例)
单票仓位 = 可投资金 × 风险系数
```

### 风险系数参考

- 高确定性机会：30-40%
- 中确定性机会：20-30%
- 低确定性机会：10-20%
- 试探性买入：5-10%

## 仓位管理策略

### 1. 金字塔建仓法（左侧交易）

```
第1次建仓：30%仓位 （目标仓位的30%）
第2次建仓：30%仓位 （目标仓位的30%）
第3次建仓：20%仓位 （目标仓位的20%）
第4次建仓：20%仓位 （目标仓位的20%）
```

### 2. 倒金字塔减仓法

```
浮盈10%：减仓 1/3
浮盈20%：减仓 1/3
浮盈30%：减仓剩余 1/3
```

### 3. 冰点加仓法

当市场出现以下信号时，使用现金加仓：
- 大盘暴跌 >5%
- 成交量极度萎缩
- 恐慌情绪蔓延
- 连续下跌后企稳

## 每周操作限制

| 操作类型 | 限制 | 原因 |
|----------|------|------|
| 买单 | ≤1笔/周 | 避免频繁交易 |
| 卖单 | ≤2笔/周 | 让利润奔跑 |

**注意**：卖单不包含止损单，止损单独计算

## 仓位检查清单

```
建仓前检查：
□ 单票仓位是否超过50%？
□ 现金储备是否低于20%？
□ 是否有更好的资金用途？
□ 这次买入的确定性有多高？

持仓检查：
□ 整体仓位是否过重？（>80%）
□ 是否有单票仓位过重？（>50%）
□ 现金是否充足？（>20%）
□ 是否需要减仓锁定利润？
```

## 特殊情况处理

### 涨停怎么办？
- 不追涨停板
- 如果持有涨停，可以部分止盈

### 跌停怎么办？
- 立即检查基本面
- 如果基本面恶化，次日止损
- 如果基本面无变化，可以等反弹

### 大涨大跌怎么办？
- 大涨不追，大跌不慌
- 按计划执行，不临时修改

## 资金分配示例

假设总资金 100 万：

```
现金储备：20万（20%）
- 日常备用：10万
- 冰点加仓：10万

分批建仓：80万（80%）
- 单票上限：40万（40%）
- 分散3-4个股票，每个10-20万

工资分配（月薪2万）：
- 现金：6666元
- 加仓1：6667元
- 加仓2：6667元
```
