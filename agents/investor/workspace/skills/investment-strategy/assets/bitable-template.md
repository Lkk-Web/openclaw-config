# 飞书Bitable记录模板

## 持仓追踪表

建议创建两个Bitable应用：

### 1. 持仓记录表 (Holdings)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 股票代码 | 单行文本 | 如 000516 |
| 股票名称 | 单行文本 | 如 国际医学 |
| 买入日期 | 日期 | |
| 买入价格 | 数字 | |
| 当前价格 | 数字 | 手动更新或API |
| 持仓数量 | 数字 | |
| 持仓成本 | 数字 | 计算字段 |
| 仓位占比 | 数字 | % |
| 盈亏金额 | 数字 | 计算字段 |
| 盈亏比例 | 数字 | % |
| 预期卖点 | 数字 | |
| 止损点 | 数字 | |
| 买入理由 | 多行文本 | |
| 备注 | 多行文本 | |

### 2. 交易记录表 (Transactions)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 交易日期 | 日期 | |
| 股票代码 | 单行文本 | |
| 股票名称 | 单行文本 | |
| 交易方向 | 单选 | 买入/卖出 |
| 交易价格 | 数字 | |
| 交易数量 | 数字 | |
| 成交金额 | 数字 | |
| 交易理由 | 多行文本 | |
| 是否按计划 | 单选 | 是/否 |
| 备注 | 多行文本 | |

### 3. 复盘记录表 (Review)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 周次 | 单行文本 | 如 2026-W13 |
| 开始日期 | 日期 | |
| 结束日期 | 日期 | |
| 买入笔数 | 数字 | |
| 卖出笔数 | 数字 | |
| 本周收益 | 数字 | % |
| 持仓收益 | 数字 | % |
| 做对的事 | 多行文本 | |
| 错的地方 | 多行文本 | |
| 下周计划 | 多行文本 | |

## 创建步骤

1. 打开飞书 → 点击「多维表格」→ 「创建多维表格」
2. 按上述字段创建表头
3. 可设置公式自动计算盈亏
4. 可设置自动化提醒

## API 集成（可选）

如需自动更新股价，可以使用：
- 第三方股票API（非实盘）
- 飞书Webhook + 定时脚本
