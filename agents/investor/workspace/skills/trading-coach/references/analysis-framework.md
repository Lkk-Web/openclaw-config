# 技术分析框架

## 一、趋势判断

### 均线系统
- **多头排列**：5日 > 10日 > 20日 > 60日 → 趋势向上，偏多操作
- **空头排列**：5日 < 10日 < 20日 < 60日 → 趋势向下，偏空或观望
- **关键均线**：20日均线（月线）是多空分界线

### MACD
- DIF > DEA 且在零轴上方 → 强势
- 金叉（DIF上穿DEA）→ 买入信号
- 死叉（DIF下穿DEA）→ 卖出信号

## 二、支撑与压力

| 类型 | 说明 |
|------|------|
| 前期高点 | 重要压力位 |
| 前期低点 | 重要支撑位 |
| 整数关口 | 心理价位（如10元、20元） |
| 均线 | 动态支撑/压力 |
| 成交密集区 | 筹码集中区域 |

## 三、量价关系

- **放量上涨** ✅ → 主力资金介入，趋势确认
- **缩量上涨** ⚠️ → 短期无压，但动能不足
- **放量下跌** ❌ → 主力出货，规避风险
- **缩量下跌** → 观望，等待企稳信号
- **天量见天价** → 顶部信号，考虑减仓

## 四、买卖时机

### 买入信号
1. 回踩均线（20日或60日）且站稳
2. 缩量调整后放量突破前高
3. 板块启动初期（龙头股刚涨停）
4. 低位出现"W底"或"头肩底"形态

### 卖出信号
1. 连续大阳后出现高位长上影线
2. 量价背离（价涨量缩到高位）
3. 跌破关键均线且无法收复
4. 个股亏损达 7-8% 止损线

## 五、仓位管理

| 市场环境 | 建议仓位 |
|----------|----------|
| 大盘强势（指数新高） | 7-9成仓 |
| 大盘震荡 | 4-6成仓 |
| 大盘弱势（连续下跌） | 1-3成仓或空仓 |

### 加减仓原则
- **分批建仓**：首仓不超过30%，确认方向再加
- **金字塔加仓**：越涨越少加，不追高满仓
- **及时止损**：亏7-8%坚决止损，不抱侥幸

## 六、A股特色规则

- **T+1**：当日买入次日才能卖出
- **涨跌停板**：主板±10%，科创板/创业板±20%
- **竞价时间**：集合竞价9:15-9:25，连续竞价9:30-15:00
- **打板技巧**：竞价尾盘（14:57后）打板成功率更高
