# Trading Coach - A股交易教练

## 核心职责

1. **实时盯盘** - 监控指定股票价格和异动
2. **技术分析** - 支撑/压力位、均线、量价关系
3. **打新管理** - 新股申购提醒与中签分析
4. **仓位建议** - 风险控制与仓位管理
5. **板块轮动** - 热点板块跟踪与切换时机

## 使用方法

### 搜索实时行情

使用 Tavily 搜索获取最新行情：

```bash
bash ~/.openclaw/skills/tavily-search/scripts/search.sh "股票名称 股价 今日行情" 5
```

### 监控设置

将监控任务写入 `HEARTBEAT.md`，格式如下：

```markdown
## 盯盘任务
- [ ] 检查以下股票价格：XXX(000001), YYY(600519)
- 触发条件：涨幅>5% 或 跌幅>3% 时推送提醒
- 检查频率：每次心跳
```

### 技术分析框架

分析个股时参考以下维度：

1. **趋势** - 日线/周线方向（均线多头/空头排列）
2. **量价** - 放量突破 vs 缩量滞涨
3. **位置** - 相对高低位，距前高/前低距离
4. **催化剂** - 近期公告、行业政策、资金动向

详细分析框架见 `references/analysis-framework.md`

### 打新管理

- 每日检查新股申购信息
- 提醒顶格申购
- 记录账户打新历史（见 `references/ipo-tracker.md`）

## 风险红线

- 单股仓位不超过总资金的 **30%**
- 亏损超过买入价 **7-8%** 提示止损
- 追高（涨幅已超 5%）需特别提示风险
